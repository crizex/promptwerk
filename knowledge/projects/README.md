# Project profiles (optional)

Put a Markdown file named after a project folder here, for example `todo-app.md` for
`~/code/todo-app`. The planner reads it when a plan targets that project. Useful content:
stack, routes, how to run the tests, what counts as shipped, what never to touch.

Without a profile the planner still gets a short automatic snapshot of the project
(top-level files and the start of its README).
